# App-Store-Unterlagen

Dieser Ordner enthält ausschließlich Store- und Marketingmaterial, keinen weiteren Source-Root.

- `icon.png`: 1024 × 1024 px, ohne Alphakanal
- `metadata/de-DE/`: deutsche Texte für App Store Connect
- `screenshots/`: echte Aufnahmen der schreibgeschützten Demo der nativen Apps

Die Screenshots zeigen ausschließlich die synthetischen Daten aus `ios/KontaKit/Sources/KontaKit/DemoData.swift`.
